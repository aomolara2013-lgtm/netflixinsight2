# NETFLIX INSIGHTS — MY PERSONAL VIEWING UNIVERSE

An interactive Netflix viewing-history analytics website built with
Streamlit, Pandas and Plotly.

## Features
- Interactive dashboard
- Year and title filters
- Viewing trends
- Movie-style title analytics
- TV episode-style analytics
- Viewing personality insights
- CSV exports

## Run locally

Install the requirements:

    pip install -r requirements.txt

Start the website:

    streamlit run app.py

Upload your Netflix viewing history CSV in the sidebar.

## Publish online

1. Create a GitHub repository.
2. Upload app.py, requirements.txt, README.md and .streamlit/config.toml.
3. Open https://share.streamlit.io/
4. Sign in with GitHub.
5. Select your repository and app.py.
6. Click Deploy.

Keep personal viewing-history files private. The app allows users
to upload their own CSV instead of requiring your private data
to be stored in a public repository.
